Support external OAuth2 JWT access tokens using a configured public key or JWKS endpoint, with issuer/audience/type/scope validation and local user billing-key bindings. Optionally provision users, billing keys, default budgets and rate limits atomically on first access, with concurrency-safe enrollment across D1, Postgres and MySQL. Preserve existing API Key authentication, budgets, rate limits, and accounting.
